# Contributing to RoomUAE

Thank you for your interest in contributing to RoomUAE ❤️

## Before You Start

Please check the existing Issues and Discussions before creating a new issue.

For large features, please open an issue first so we can discuss the proposed approach.

## Development Workflow

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Add or update tests when appropriate.
5. Run the test suite.
6. Open a Pull Request.

Example:

```bash
git checkout -b feature/search-filters
```

## Commit Messages

Use clear commit messages.

Examples:

```text
feat: add listing search filters
fix: resolve mobile listing card layout
docs: improve installation instructions
test: add listing availability tests
```

## Pull Requests

Please include:

* What changed?
* Why was it changed?
* How was it tested?
* Screenshots for UI changes.

Keep Pull Requests focused on one feature or fix.

## Code Quality

Please follow the existing Laravel project structure and coding conventions.

Avoid unrelated changes in the same Pull Request.

## Questions

If you are unsure about an implementation, open an Issue or Discussion before making a large change.

Thank you for helping build RoomUAE! 🇦🇪
